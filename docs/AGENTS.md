# 계약·근거 문서

루트 [AGENTS.md](../AGENTS.md)를 따른다.

- [GRAPH-EXCHANGE.md](GRAPH-EXCHANGE.md)가 producer/consumer 공유 계약이다.
  의미·버전 변경을 먼저 합의하고 영향받는 모든 자매 저장소의 동시 PR·호환 검증을 계획한다.
- 필드 의미·역할·target·미해석/동적 값·위치·시각·입력 상한을 명시한다.
  형식이 보장하는 것과 현재 구현의 관찰 범위를 구분한다.
- [PRD](PRD.md)는 제품 의도, [PLAN](PLAN.md)은 실행 순서, [RESEARCH](RESEARCH.md)는 사실/가정의 근거다.
  출시·지원·성능·정확도 주장은 확인 시점과 코드·검사·공식 출처를 남긴다.
- README·CHANGELOG·배포 스킬의 사용법과 일치시킨다. 조사 메모는 구현 완료나 작업 승인이 아니다.
  합성 corpus·공개 하네스·실제 앱 빌드가 입증하는 범위를 구분한다.
- 공식 모델 권고의 적용 근거·평가 기록은 선택적으로 읽는 문서에 둔다.
  긴 가이드나 자주 바뀌는 모델 설정을 항상 읽는 AGENTS에 복사하지 않는다.
